The Style Atribute

The HTML style attribute provides inline styling for individual HTML elements using CSS property-value pairs. It overrides styles set in external stylesheets or style tags, offering a way to quickly format elements like colors or fonts directly within the tag, although it is considered bad practice for large, maintainable works. 

Inline Styling: The style attribute applies CSS rules directly within the element's opening tag,
making the styles specific only to that element.
Syntax: The value of the attribute is one or more 
CSS property: value; pairs, separated by semicolons.
Precedence: Inline styles have high priority and will override styles set in an internal 
style sheet or an external style sheet, unless !important is used in the external/internal CSS.
Global Attribute: It can be used on any HTML element, such as etc..

html style="color: blue; font-size: 16px; background-color: lightgray;">

(This is a paragraph with inline styles.)
